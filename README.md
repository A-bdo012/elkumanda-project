# elkumanda - E-Commerce Management System

نظام إدارة متكامل لمتاجر التجارة الإلكترونية، تم تطويره باستخدام PHP و MySQL لتوفير لوحة تحكم سلسة لإدارة المنتجات والأقسام والمبيعات.

## 🚀 المميزات الرئيسية (Features)
- **إدارة المنتجات:** إضافة، تعديل، وحذف المنتجات بسهولة.
- **إدارة العلامات التجارية والكوبونات:** التحكم في الماركات وخصومات الكوبونات.
- **لوحة تحكم إدارية:** واجهة مستخدم متجاوبة وشاملة لإدارة المتجر.
- **إدارة قاعدة البيانات:** هيكلة مرنة للتعامل مع البيانات بسرعة وكفاءة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript, Bootstrap (SB Admin 2)
- **Local Server:** XAMPP
